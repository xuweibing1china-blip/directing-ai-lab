# DIRECTING AI｜图片反转故事离线游戏

Issue #1 的 P0 课堂 MVP：老师用一台笔记本投影，带全班依次经历观察、两次线索、占位结局与复盘。无账号、无服务器、无网络依赖。

> 首版使用自制 SVG 与匿名占位剧情，只代表工程流程完成；真实图片、最终故事与结局仍待课程主创确认。

## 直接运行

1. 下载或 clone 整个文件夹。
2. 断开网络（可选，用来验收离线能力）。
3. 双击 `index.html`，以浏览器的 `file://` 模式打开；不需要 npm 或本地服务器。
4. 将浏览器设为全屏后投影。

老师可按画面按钮，也可用 `←`、`→` 切换幕次，按 `R` 重置全场。计时器可独立开始、暂停及重设；换幕时会自动暂停，避免讨论期间继续倒数。

## 替换故事素材

- `story-data.js`：改标题、提示、各幕文字、已揭示线索、20 秒默认时间。
- `index.html` 内的 `<svg>`：替换占位场景。若改用本地图片，请把有授权的文件放入仓库，例如 `assets/scene.webp`，再使用相对路径；不要引用网址。
- 保留 5 个 `stages`（`start`、`clue-1`、`clue-2`、`ending`、`review`），即可沿用进度与键盘控制。
- 新故事上课前，请由主创确认图片授权、线索、结局与复盘问题。

## JavaScript 失灵时的降级方案

直接打开 `fallback.html`。它把五幕依次排成静态页面，可向下滚动讲授，也可由浏览器打印为 PDF 后逐页播放。建议老师课前把该页另存 PDF，作为无法临时排查时的备份。

## 测试与课前检查

自动 smoke test（需 Node.js，但运行游戏本身不需要）：

```sh
node tests/smoke-test.mjs
```

手动验收清单：

- 断网并双击 `index.html`，确认画面与控制全部可用。
- 从观察走到复盘，确认尚未到达的线索与结局不会提前显示。
- 启动、暂停、重设计时器；按 `R` 后确认幕次与时间回到初始值。
- 用 `←`、`→` 完整走一次，第一幕不能再后退、复盘不能再前进。
- 以投影分辨率、普通笔记本、手机／平板各检查一次字号、对比与按钮。
- 关闭 JavaScript 或直接打开 `fallback.html`，确认静态五幕可讲授。

这些工程检查不能取代真实课堂实测；首课后再记录现场问题。
