# DIRECTING AI LAB｜《摆脱八十分》课堂实验室

## 项目目的
服务浙江城市学院18位跨专业、大二、AI创作初学者的 **90分钟《摆脱八十分》课程**，并沉淀可复用的创作教学工具。

课程不是软件工具展销，而是带学生从“能生成”走到“能提出创意并解释判断”。

## 90分钟课程结构（包含休息）
- **00—07分钟｜破冰**：图片反转故事，练习重新理解画面。
- **07—50分钟｜上半场：先得到八十分**：认识行业、AI文字／图像／视频／音乐／音效／剪辑工具与基本工作流。
- **50—55分钟｜中场**：“2036年的我”职业时间胶囊／匿名未来墙。
- **55—90分钟｜下半场：摆脱八十分**：从Point、Idea到Judgment，贯穿文字、画面、声音、视频的创作案例；发布《世界异闻录》18人共创任务。

## 工程任务（按优先级）
1. **P0** 图片反转故事离线游戏（课前必须可用）。
2. **P1** 2036职业未来墙（课前准备学生自愿提交的匿名内容；演示端离线可用）。
3. **P2** 《世界异闻录》18人共创工作台（可在课后逐步上线）。

详细需求、验收条件及非目标见本仓库 Issues。

## 制作约束
- 首课设备可能老旧，学生多为普通笔记本／平板／手机；**老师投影端的离线可用性优先**。
- 不依赖付费API、外部CDN、注册、实时模型调用或稳定网络。
- 当前仓库公开，**不得提交学生个人信息、未获授权作品或内部私有素材**。示例使用自制／占位素材。
- 保持教学与技术分离：**创｜想道**（意图、创意、判断）及 **作｜做道**（工作流、制作、交付）。
- 所有实际代码通过功能验收、离线验收、键盘操作和移动端显示检查后再合入主分支。

## 工程开始方式
给 Codex 指定此 GitHub 仓库，并令其从标注 P0 的 Issue 开始实现。由工程任务的 Pull Request、自动测试和现场浏览器演示作为完成证据。创建 Issue 不代表 Codex 已自动开始运行。

## 创意判断
反转故事的剧情、线索和最终答案由课程主创确认；程序只负责可靠呈现，不自动替代创意判断。
